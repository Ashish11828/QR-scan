## Local setup

1. Clone the repository on macOS and open the project or workspace in Xcode.
2. Review deployment targets, dependency configuration, and signing settings.
3. Configure your own development team and any required backend services.
4. Build for a compatible simulator or physical device.

Locate the Xcode project in the imported source and review camera permissions and device requirements before running.
